
# Technology Playground 🚀

This repository is created as a **sandbox for experimenting and practicing new technologies** before applying them to real-world projects.  
Each practice or experiment will live in its **own dedicated branch**, keeping the `main` branch clean.

---

## 📌 Structure
- `main` → The base branch with no direct experiments.
- `feature/*` or `experiment/*` → Branches where different technologies, tools, or ideas are tested.

## ✅ How to Use
1. Checkout the branch you want to explore:
   ```bash
   git checkout <branch-name>
   ```
2. Review the code, notes, and experiments within that branch.

3. Create your own experimental branch when testing something new:
   ```bash
   git checkout -b experiment/<tech-or-feature>
   ```

---

## 🎯 Purpose

This repo is purely for learning, testing, and exploration.
It helps ensure that new technologies are well-understood before being implemented in production-grade projects.
